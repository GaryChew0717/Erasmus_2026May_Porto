# CareQuest — Erasmus Team Project, Porto 2026

CareQuest is an interactive web platform designed to give children a safe space for learning, creativity and connection during recovery. It was built in one week by an international team of six students (from DkIT and partner universities) during an Erasmus intensive project in Porto, Portugal.

## Project background

- **Programme:** Erasmus intensive project, Porto, Portugal (May 2026)
- **Duration:** one week
- **Team:** six students from DkIT and partner universities
- **Goal:** design and build a working web platform for children during recovery, from planning to delivery, within a fixed deadline

## My contribution

I worked on the front-end interface: the navigation and the responsive layout. I also coordinated daily with teammates from different universities to meet the deadline.

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/GaryChew0717/Erasmus_2026May_Porto.git
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open the local address shown in the terminal.
